# Can I edit or delete a Moment?

**In the Eternus app**, you can edit your own Moments — the title, story, date or period, location and who can see it (its layers) — and you can delete them.

**Media while editing:** the photos, video or voice already in a Moment are kept when you edit it. Adding or replacing media while editing isn't fully supported yet, so new or replacement media chosen while editing may not be saved.

**Eternus Web doesn't currently let you edit or delete Moments.**

Changing a Moment's layers changes who can see it from then on. Deleting a Moment removes it from Eternus, including for the people it was shared with. It can't remove copies others made outside Eternus.

You can only edit or delete Moments you created. Being able to see someone else's Moment doesn't let you change it.
