# Which devices and platforms can I use?

Eternus is available in two ways:

- **the Eternus mobile app**, which offers the broader Eternus experience;
- **Eternus Web**, which works in a web browser on a computer or a phone, at **app.myeternusapp.com**.

Both use the same Eternus account. You sign in with the same email address and password, and you see the same Moments, people and access.

The current mobile experience has been verified on Android. Support for other mobile platforms, such as iPhone (iOS), has not been confirmed.

Opening Eternus Web in a phone's browser gives you Eternus Web, not the mobile app. Some app features aren't available on Eternus Web (see *What can I do on Eternus Web?*).
